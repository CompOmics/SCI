# Spectronaut — Main Analysis Figures

Figures from the main SCI analysis pipeline run on Spectronaut search results.
The structure and content are identical to the [DIA-NN v2.6 figures](../0_DIANN/v2.6/README.md);
only the underlying data differs.

Generated by running the same notebooks as for DIA-NN with the environment variable
`SCI_FIGURES_DIR` set to this directory (`Figures/1_Spectronaut/`).

---

## Structure

```
1_Spectronaut/
├── Figure_3/
│   ├── count_boxplots/    Precursor/protein ID counts and contaminants
│   ├── CV/                Coefficients of variation
│   └── ID_Heatmap/        Per-lab missingness heatmaps
├── Figure_4/
│   ├── Completeness/      Completeness curves
│   ├── Plate_Heatmap/     Per-well identification count heatmaps
│   ├── RT_Stability/      Retention time stability
│   └── Drift/             Drift over time (Across_days, Within_day, Correlation, Injection, RT)
├── Figure_5/
│   ├── Diagnostic_plots/  Missingness equalisation diagnostics
│   ├── Intralab/          Intra-lab pairwise correlations
│   ├── Interlab/          Inter-lab median correlation heatmaps
│   ├── Instrument/        Correlations by instrument type
│   ├── Pairwise_examples/ Example cell-pair scatter plots
│   └── Reproducibility/   Reproducibility summary panels
└── Figure_6/
    ├── scplainer/
    │   ├── base/          scplainer variance and GMF figures
    │   ├── QC/            QC scatter panels
    │   └── filter_samples/ Variant with sample filtering applied (Spectronaut-specific)
    ├── VariancePartition/ variancePartition violin and PCA plots
    └── MSqRob/            MSqRob DE volcano, UpSet, and PCA plots
```

For a detailed description of each file, see the
[DIA-NN v2.6 README](../0_DIANN/v2.6/README.md) — the file names and descriptions are
the same. The Spectronaut set has one additional subfolder:
**`Figure_6/scplainer/filter_samples/`**, which contains the scplainer output from a
variant run with sample filtering applied.
