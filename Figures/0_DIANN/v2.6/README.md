# DIA-NN v2.6 — Main Analysis Figures

Figures from the main SCI analysis pipeline run on DIA-NN 2.6 (second pass) results.
Organised by paper figure section.

The equivalent Spectronaut figure set lives in [`../../1_Spectronaut/`](../../1_Spectronaut/README.md)
and is generated by running the same notebooks with `SCI_FIGURES_DIR` pointing there.

**All files are saved in png + svg + pdf unless noted otherwise.**

Labs: Astral_1–6, timsTOF_1–3.
Conditions: K562, HEK293T (single-cell); QC — HeLa, Site specific QC (quality controls).

## Figure 5 — Sample Correlations

**Notebook:** [`3_Correlations/01_sample_correlations.ipynb`](../../../Notebooks/3_Correlations/01_sample_correlations.ipynb)

File naming convention: `{condition}_{method}_{type}.png`
Conditions: K562, HEK293T, `Site specific QC`, `QC - Hela`.
Methods: pearson, spearman.

### `Figure_5/Diagnostic_plots/`

| File | Description |
|------|-------------|
| `pct_masking` | % values masked per lab to equalise missingness |
| `masking_heatmap_{condition}` | Binary protein ID heatmap after equalisation, per condition |
| `missingness_distribution_protein_{subset}` | KDE of per-protein missingness fraction with KS test matrix |
| `missingness_distribution_sample_{subset}` | KDE of per-sample missingness fraction |
| `Coobserved_diagnostic_plot` | Co-observed protein count KDE and count vs correlation scatter |

### `Figure_5/Intralab/`

Violin plots of intra-lab pairwise correlations per lab:

| File pattern | Description |
|------|-------------|
| `{condition}_{method}_intralab.png` | One file per condition × method combination |

### `Figure_5/Interlab/`

Hierarchically clustered heatmaps of median inter-lab correlations (diagonal = intra-lab):

| File pattern | Description |
|------|-------------|
| `{condition}_{method}_interlab_heatmap.png` | One file per condition × method combination |

### `Figure_5/Instrument/`

Violin plots grouped by instrument platform combination:

| File pattern | Description |
|------|-------------|
| `{condition}_{method}_instrument.png` | Intra-lab / same-instrument inter-lab / mixed-instrument inter-lab |

### `Figure_5/Pairwise_examples/`

| File | Description |
|------|-------------|
| `Astral_1__Astral_2__pearson85_90` | Scatter of log2 intensities for cell pairs with Pearson r in [0.85, 0.90] |

### `Figure_5/Reproducibility/`
