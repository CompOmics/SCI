# Figures

Navigation guide for all figure outputs of the SCI single-cell proteomics study.

Each figure is saved in three formats: **png**, **svg**, and **pdf** (unless noted otherwise).
Figure files are grouped by paper section, then by search engine where applicable.

---

## Directory structure

```
Figures/
├── Figure_1/                   Static overview figures (manually assembled)
├── Figure_2/                   Multi-engine benchmarking (ProteoBench)
├── 0_DIANN/v2.6/               DIA-NN 2.6 main analysis
│   ├── Figure_3/               Identification counts and CVs
│   ├── Figure_4/               QC metrics and drift over time
│   ├── Figure_5/               Sample correlations
│   └── Figure_6/               Variance partitioning and differential expression
├── 1_Spectronaut/              Spectronaut main analysis (same structure as 0_DIANN)
│   ├── Figure_3/
│   ├── Figure_4/
│   ├── Figure_5/
│   └── Figure_6/
└── software_comparison/        Cross-engine comparison figures (DIA-NN 2.2/2.6 vs Spectronaut)
```

> Spectronaut figures are generated by running the same notebooks as for DIA-NN, with the
> environment variable `SCI_FIGURES_DIR` pointing to `Figures/1_Spectronaut/` instead of
> `Figures/0_DIANN/v2.6/`.
