# 1_QCQuant

Search engine benchmarking on the quantitative QC mixtures (three-species samples with known ratios). These notebooks parse the results of six DIA search engines into ProteoBench format and compare identification depth, quantification accuracy, dynamic range, feature overlap, and precursor characteristics. Figures produced here correspond to Figure 2 of the manuscript.

Notebook `01_parse_results.ipynb` reads the raw search results. Notebooks `02` to `05` all consume the parsed `datapoints.pkl` and `intermediates.pkl` objects, which can either be regenerated by `01` or downloaded directly from Zenodo, and can therefore be run independently once those files are available.

## Notebooks

### [01_parse_results.ipynb](01_parse_results.ipynb)
Reads search engine output (DIA-NN, Spectronaut, AlphaDIA, PEAKS, Chimerys/MSAID, FragPipe) from the `QC_Quant` result tree and parses each result folder into ProteoBench format. Applies per-engine q-value filters and quantity-column selection, uses a per-entry pickle cache so only new entries are processed, and writes the combined `datapoints.pkl` and `intermediates.pkl`.

### [02_Settings_comparison.ipynb](02_Settings_comparison.ipynb)
Provides an overview of which engines, settings, and datasets were included, then produces the count-versus-error benchmark scatter figures. Compares tools across all settings, per tool, split by instrument type (Astral versus timsTOF), and for recommended settings only. The x-axis is the mean absolute quantification error, the y-axis is the number of identified precursors, so upper-left is best.

### [03_Performance_comparison.ipynb](03_Performance_comparison.ipynb)
Focuses on dynamic range and quantification accuracy using the single best setting per tool. Produces KDE plots of measured versus expected log2 fold changes per species, MA-plots per lab and pooled per instrument type, pairwise error comparisons, and multi-tool dynamic-range curves computed on precursors matched across all recommended tools.

### [04_Overlap_between_search_engines.ipynb](04_Overlap_between_search_engines.ipynb)
Compares precursor overlap and quantification error across the six engines for all nine labs. Produces a 3x3 UpSet panel (one panel per lab) of precursor overlap and a matching 3x3 boxplot panel of the absolute log2 fold-change error for precursors unique to a tool versus precursors shared by all tools.

### [05_PrecursorCharacteristics.ipynb](05_PrecursorCharacteristics.ipynb)
Compares peptide-level precursor characteristics (length, charge state, missed cleavages, modification classes) across engines, using the best setting per tool. Reports both the global set of identified precursors and the subset excluding the all-tools intersection, with labs grouped by instrument type.
